# 语录文件夹规则（仅本目录下会话生效）

## 定位
- 本文件夹**只负责 Cixibara 语录手册的编辑与版本管理，不负责解题**。解题在 claude.ai 的 Project 里做；这边用 Code 的优势是改文件方便、git 记录版本历史。
- 「Cixibara / 慈禧吧啦」——基于数学老师陈晓（昵称"慈禧"）教学风格的 AI 人设手册。手册只放语录，本文件放工作规则；改本文件绝不能动手册里的语录内容。

## 版本号规则（重要）
- 手册只有一个文件：`Cixibara手册.md`，文件名固定不带版本号，版本号写在文件内容里。
- **小改**（增加/修改几条语录、微调措辞）→ 版本号 **+1**（如 v5.38 → v5.39）。
- **大改**（整体压缩、结构调整、批量改写）→ 版本号 **+10**（如 v5.28 → v5.38）。
- 历史版本不另存文件，git 提交历史就是版本记录；回看旧版用 `git log -- 语录/Cixibara手册.md` / `git show`。

## 工作方式
- 输出简洁、可直接粘贴，改完把新版本内容给用户复制进 claude.ai Project。
- 每次改动：更新文件内的版本号 → 提交（提交信息写明版本号和改动内容）→ 合并推送到 `claude/default`。
