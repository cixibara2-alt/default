# 语录文件夹规则（仅本目录下会话生效）

## 定位
- 本文件夹**只负责 Cixibara 语录手册的编辑与版本管理，不负责解题**。解题在 claude.ai 的 Project 里做；这边用 Code 的优势是改文件方便、git 记录版本历史。
- 「Cixibara」——基于数学老师陈晓（昵称"慈禧"）教学风格的 AI 人设手册。手册只放语录，本文件放工作规则；改本文件绝不能动手册里的语录内容。

## 版本号规则（重要，同一天内只按当天最终结果加一次）
- 手册只有一个文件：`Cixibara手册.md`，文件名固定不带版本号，版本号写在文件内容里。
- **小改**（增加/修改几条语录、微调措辞）→ 版本号 **+1**（如 v5.38 → v5.39）。
- **大改**（整体压缩、结构调整、批量改写）→ 版本号 **+10**（如 v5.28 → v5.38）。
- 一天之内不按编辑次数累加：当天全程都是小改 → 只加 1；当天只要出现过一次大改（不论之前有没有小改）→ 当天整体按加 10 算，且当天后续无论再怎么改，增量都封顶在 10，不会在这基础上再加。
- 历史版本不另存文件，git 提交历史就是版本记录；回看旧版用 `git log -- 语录/Cixibara手册.md` / `git show`。

## 工作方式
- 输出简洁、可直接粘贴，改完把新版本内容给用户复制进 claude.ai Project。
- 每次改动：更新文件内的版本号 → 提交（提交信息写明版本号和改动内容）→ 合并推送到 `claude/default`。
- **改语录时**：主动检查是否有"如果被领导看到会有不良影响"的夸张/敏感表述（如影射老师失职、贬低/侮辱学生、拿真实病症开玩笑等），发现了提出来给用户判断，不擅自改写语录内容。

## 配图（GGB 文件，不再截图）
- 需要几何配图时直接生成 **`.ggb` 文件**：手写 `geogebra.xml`（GeoGebra format 5.0，点/线/圆等对象与标签样式全 XML 描述）→ `zip` 打包成 `.ggb`（包内根为 `geogebra.xml`，缩略图可省）→ 交付。不跑无头浏览器截图，不生成 PNG。
- **交付渠道（已验证可用）**：默认聊天里 SendUserFile 直接发（iOS 上点附件 → 分享 → GeoGebra 打开，用户确认这个最方便）；用户要留档时再存一份到 Google Drive 的「GGB配图」文件夹（已建好）。
- GGB 文件按需生成即用，不存进本仓库。
