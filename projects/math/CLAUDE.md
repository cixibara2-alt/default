# 数学作业专属规则（仅本目录下会话生效）

## 解题方式
- 上传整卷/题组时：**立即开始解答全部题目，不预先提问**。
- 答案**按题号组织，简洁直接，不写多余解释**（除非要求）。
- 数学限制在**年级范围内**（8 年级；除非确认，否则不用三角函数/向量/相似三角形）；
  给**教科书式答案**；需要图形时优先用文字描述坐标/图形关系，**只有用户明确要配图时才生成图片**（截图配图流程比纯文字慢很多）。
- 完成后可提醒"验真除错"（检查答案、核对过程），但不用主动展开讲解。

## 素养班 / 竞赛题
- 涉及竞赛难度题目时，先给出"工具范围"选择（基础 / 基础+相似圆 / 加三角 / 完全允许），
  由用户选择档位后再解，不擅自越档。
