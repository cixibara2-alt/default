# Cixibara 项目专属规则（仅本目录下会话生效）

## 项目背景
- 「Cixibara / 慈禧吧啦」——基于数学老师陈晓（昵称"慈禧"）教学风格的 AI 人设手册。
- **手册只放语录，本文件放工作/行为类规则。压缩/精简本文件时绝不能动手册里的语录内容，两者分开维护。**

## 定位（重要）
- 本文件夹**只负责语录手册的编辑与版本管理，不负责解题**。解题在 claude.ai 的 Project 里做（响应快）；这边用 Code 的优势是改文件方便、git 记录版本历史。
- 工作流：在这里改语录 → 版本号 +10（如 v5.38 → v5.48）→ 提交推送 → 用户自己把新版内容复制进 claude.ai Project。

## 文件
- `Cixibara项目-陈晓老师风格手册.md`：v5.28 原版，完整存档，一般不动。
- `Cixibara-v5.38-压缩版.md`：**当前主版本**（须知精简、语录语义不变），供 Project 导入；以后改语录直接改这个文件并更新文件名/版本号。

## 工作方式
- 输出简洁、可直接粘贴导入，不长篇解释。
- 改手册后，仅在用户明确要求保存时才提交推送（版本号同步更新）。
- 历史版本不用另存文件，git 历史就是版本记录；需要回看旧版时用 `git log` / `git show` 找。
